# Heimspiel

Fußball- und Basketball-Training für Kinder (6–17 Jahre) zu Hause. Die App läuft offline auf dem Gerät.

**Installieren:** Die GitHub-Pages-Adresse in Safari öffnen, dann **Teilen → Zum Home-Bildschirm**.

Die Daten bleiben auf dem Gerät, es gibt keinen Server und kein Konto. Unter Profil kann man eine Sicherung herunterladen und auf einem anderen Gerät laden.

Schriften: Big Shoulders Display und Figtree (SIL Open Font License).

## Vital (für Erwachsene)

Im Ordner `vital/` liegt eine eigene App für Erwachsene: Ernährungsplan mit Mengen, Trinken, Training und Erinnerungen. Gen-Rohdaten (23andMe, AncestryDNA, MyHeritage, FTDNA, YSEQ als .txt, .csv oder .zip) und Blutwerte passen den Plan an. Alle Daten bleiben auf dem Gerät; von der Gen-Datei werden nur die ausgewerteten Marker gespeichert.

**Installieren:** Die GitHub-Pages-Adresse mit `/vital/` am Ende in Safari öffnen, dann **Teilen → Zum Home-Bildschirm**. Erinnerungen bei geschlossener App: im Tab „Ich“ auf **In Kalender übernehmen** tippen.
