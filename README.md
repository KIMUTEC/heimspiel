# Heimspiel

Fußball- und Basketball-Training für Kinder (6–17 Jahre) zu Hause. Die App läuft offline auf dem Gerät.

**Installieren:** Die GitHub-Pages-Adresse in Safari öffnen, dann **Teilen → Zum Home-Bildschirm**.

Die Daten bleiben auf dem Gerät, es gibt keinen Server und kein Konto. Unter Profil kann man eine Sicherung herunterladen und auf einem anderen Gerät laden.

Schriften: Big Shoulders Display und Figtree (SIL Open Font License).

## Robo-Held (Spiel)

Ein Jump'n'Run im Retro-Stil mit Waffen, unter `robo/`. Drei Roboter-Bosse, jeder hinterlässt eine neue Waffe, danach wartet Dr. Zahnrad. Fortschritt wird auf dem Gerät gespeichert.

**Spielen:** `<GitHub-Pages-Adresse>/robo/` in Safari öffnen, dann **Teilen → Zum Home-Bildschirm**. Quer halten für das große Bild.

Steuerung: Steuerkreuz laufen/klettern, A springen, B schießen (gedrückt halten = Superschuss), WAFFE wechselt die Waffe. Tastatur: Pfeile, Z, X, C, Enter.

Schrift: Press Start 2P (SIL Open Font License).
